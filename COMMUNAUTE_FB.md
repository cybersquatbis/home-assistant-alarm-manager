# Publication Facebook — Alarme Manager Community

🛡️ **Alarme Manager Community — quelle différence avec Alarmo ?**

**Alarmo = la centrale d'alarme.** Il gère l'armement, le désarmement, les modes, les capteurs et le déclenchement.

**Alarme Manager = la couche de supervision et d'orchestration autour de la centrale.** L'idée n'est pas de remplacer Alarmo, mais d'ajouter un plan maison, le contexte des ouvrants et mouvements, les caméras, les captures, les lumières de dissuasion, la sirène avec garde-fous, les notifications, la surveillance RF, l'historique et l'état de santé.

Exemple : **Alarmo dit « Intrusion détectée. »** Alarme Manager peut alors contextualiser ce qui se passe, où, avec quels capteurs et quelles réactions sont autorisées.

Les deux sont donc **complémentaires**, pas concurrents.

La version Community est générique, sans entités personnelles, se configure depuis Home Assistant et démarre en **OBSERVATION** par défaut.

Le but final : transformer Home Assistant en vrai **poste de supervision sécurité maison**, visuel, configurable et évolutif.

> La beta actuelle ne couvre pas encore toute la feuille de route. Le README distingue les fonctions opérationnelles de celles restant à enrichir.
