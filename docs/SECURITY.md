# Sécurité et tests

Alarme Manager Community n'est pas un système d'alarme certifié.

Garde-fous : OBSERVATION par défaut, réactions physiques désactivées par défaut, confirmation obligatoire pour passer en ACTIF, tests de sortie limités à 10 secondes, sirène automatique limitée à 300 secondes, simulation sans commande physique et garde interne contre les réactions simultanées.

Procédure conseillée : vérifier chaque capteur, corriger les indisponibilités, simuler en OBSERVATION, tester séparément notifications/caméras/lumières/sirène, puis n'activer les réactions qu'après validation sur place.
