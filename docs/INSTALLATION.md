# Installation

Copiez `custom_components/alarme_manager/` dans `/config/custom_components/alarme_manager/`, redémarrez Home Assistant puis ajoutez **Alarme Manager Community** depuis Paramètres → Appareils et services.

Avec HACS, ajoutez `cybersquatbis/home-assistant-alarm-manager` comme dépôt personnalisé de type Integration.

Au premier démarrage, restez en **OBSERVATION**, configurez la centrale et les équipements, simulez un incident, puis testez séparément les sorties avant toute activation réelle.
